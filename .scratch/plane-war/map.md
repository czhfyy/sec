# 飞机大战 · 决策地图

## Destination

先产出一版可玩的「飞机大战」原型：单文件 HTML + Canvas、像素复古风、键盘（WASD/方向键）移动 + 自动开火、基础版玩法（移动、射击、碰撞、计分、生命、结束重开）。原型试玩后，再按反馈迭代成可发布版本。

## Notes

- 技术载体：单文件 HTML（内联 CSS/JS），Canvas 2D，零外部依赖，双击即玩
- 美术：像素复古；操作：键盘 + 自动开火；玩法范围：基础版
- 用户偏好：代码尽量简化、避免复杂实现；讲解/说明需配源代码片段与运行截图
- 覆盖默认：本 effort 显式覆盖 wayfinder 的「只规划不执行」默认——`prototype` 与 `task` ticket 允许直接写代码并在浏览器验证

## Decisions so far

<!-- 每关闭一个 ticket 追加一行：- [ticket 名称](issues/NN-xxx.md): 一行结论 gist -->

- [原型核心规则与数值](issues/01-core-rules.md)：1 命即死；击杀小型 +1/中型 +3，存活每秒 +1；5 档难度每 20 分升档（生成间隔 1.2→0.4 秒、下落速度 60→120 px/s），满档封顶；中型机 10% 概率出现、每 2 秒射 1 发 80 px/s 直线弹
- [像素风规格与画布适配](issues/02-pixel-visual.md)：逻辑分辨率 320×480，整数倍缩放+居中黑边（窗口更小时等比缩小）；sprite 用字符矩阵+调色板逐格 fillRect；HUD 等宽 8px；黑白红黄调色板；背景滚动速度线；静态扫描线滤镜（隔行 25% 黑）
- [可玩原型第一版](issues/03-playable-prototype.md)：单文件 `prototype/plane-war.html` 已可玩；开始/移动/自动射击/击杀/撞击结束/重开均通过浏览器实测，控制台无 JS 错误
