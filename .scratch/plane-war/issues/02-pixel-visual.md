# 像素风规格与画布适配

Type: grilling
Status: resolved

## Question

像素复古风具体怎么实现、画布怎么适配？需要定清：

- 逻辑分辨率取多少（如 320×480），窗口如何放大
- 缩放策略：整数倍放大、保持比例、居中留边
- 像素绘制方式：逐像素 sprite 矩阵 / `fillRect` 拼小方块 / 低分辨率离屏 Canvas 放大
- HUD（分数、生命）用像素点阵字体还是 Canvas 文本
- 是否加扫描线/CRT 滤镜

## Answer

**逻辑分辨率与缩放**

- 逻辑画布 320×480（2:3），所有坐标与尺寸按逻辑像素设计。
- canvas 内部尺寸固定 320×480；显示时取 `min(窗口宽/320, 窗口高/480)` 的整数倍（≥1）放大，`image-rendering: pixelated`，保持比例、居中，多余区域留黑边。
- 窗口小于 320×480 时退化为等比缩小（非整数倍），保证画面完整可见。

**像素 sprite**

- 用字符矩阵定义（如 `..XX..`），配调色板逐格 `fillRect(x + col, y + row, 1, 1)`。
- 每种 sprite 一张字符矩阵加一张颜色映射表，改外观只改字符。

**调色板（黑白红黄）**

| 用途 | 颜色 |
| --- | --- |
| 背景 | `#000000` |
| 滚动速度线 | `#2A2A2A` |
| 玩家机 | `#E43B44`（红） |
| 玩家子弹 | `#FFFFFF`（白） |
| 敌机 | `#FFD24A`（黄），中型带 `#FF8C42` 核心 |
| 敌弹 | `#FF8C42`（橙黄） |
| HUD 文字 | `#FFFFFF` |

**背景**

- 纵向滚动速度线：背景上绘制若干等距竖细线，按当前档位速度向下滚动并循环，制造俯冲感。

**HUD 与文字**

- Canvas `fillText` + 等宽字体 8px，在逻辑分辨率上绘制；开始/结束提示同字体居中。
- 不引入外部字体文件。

**扫描线滤镜**

- 场景绘制完成后，每隔 1 行叠一层 `rgba(0,0,0,0.25)` 的 1px 横线，覆盖整个画布。
- 不加暗角、不加闪烁。
